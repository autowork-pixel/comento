# 코멘토 광고 실습실

메타 트래픽·전환 캠페인과 네이버 파워링크를 연습하는 교육용 시뮬레이터의 첫 화면입니다. `index.html`을 브라우저에서 열면 동작합니다. Netlify 정적 배포도 가능합니다.

## 현재 범위

- 캠페인별 설정 폼과 7일·100만 원 기준 결과 화면
- 교육용 고정 CTR·CPC·전환율을 명시한 시뮬레이션
- `?learner=이름` 화면 표시 예시. 이는 인증이나 개별 접근 제어가 아닙니다.

## 시트 연동 설계

원본 시트: `코멘토 수강생` / `시트1` / `회차, 수강 시작, 수강 종료, 수강생명, 링크, 만료여부`.

서버 함수가 Google Sheets API로 행을 읽고, 신규 수강생마다 추측 불가능한 토큰을 생성해 저장한 뒤 `링크` 열에 URL을 기록합니다. 링크 접속 시 서버가 토큰과 만료일을 검증해야 합니다. 시트 접근 자격 증명과 AI·네이버 API 키는 서버 환경 변수로 보관합니다. 공개 HTML이나 URL에 저장하지 않습니다.

현재 화면은 시트 동기화, 접근 제어, 이미지 업로드, AI 소재 평가, 플랫폼 API, 결과 저장이 연결되지 않은 프로토타입입니다. 실제 플랫폼 데이터를 활용할 때에도 시뮬레이션 추정치와 실제 데이터의 출처를 구분해 표시해야 합니다.
