# 코멘토 광고 실습실

`index.html`은 네이버애즈 파워링크 실습 화면입니다. Meta 실습 초안은 `studio.html`에 분리했습니다.

## 네이버 파워링크 현재 범위

- 네이버애즈의 왼쪽 검색광고 메뉴와 파워링크 목록 화면
- 캠페인 → 광고그룹 → 키워드·소재 계층과 상세 화면
- 캠페인 이름, 하루 예산·제한 없음, 기간, 균등 배분
- 광고그룹 URL, 기본 입찰가, 하루 예산, 매체·지역·가중치
- 키워드 최대 100개 등록, 소재 제목 15자 및 설명 20~45자 검증, PC·모바일 연결 URL
- 목록 검색, ON/OFF, 복제, 삭제. 저장은 현재 브라우저의 localStorage만 사용

현재 키워드 입찰가 변경, 제외 검색어, 단일형·반응형 소재, 확장 소재와 XLSX 다운로드를 지원합니다. 광고그룹 화면의 **7일 성과 시뮬레이션**은 키워드·소재 문구의 연관도, 확장 소재 수, 입찰가, 수동 입력한 월간 검색량·기본 CTR·전환율을 조합하는 결정적 학습 모델입니다. 입력한 예산이 반드시 모두 소진되는 것은 아닙니다. 결과와 가정을 화면에서 확인하고 XLSX로 내려받을 수 있습니다.

실제 광고 계정에는 등록되지 않고 광고비가 결제되지 않습니다. 네이버 키워드 조회와 OpenAI 소재 평가 서버 함수는 구현됐지만 수강생별 접근 제어가 완성되기 전까지 잠겨 있습니다. 따라서 시뮬레이션 수치는 실제 광고 성과 예측이 아닙니다. 시트 기반 개별 링크·만료 검증과 서버 저장도 다음 단계입니다.

Netlify의 `netlify/functions/keywords.mjs`는 서버 환경변수 `NAVER_API_KEY`, `NAVER_SECRET_KEY`, `NAVER_CUSTOMER_ID`로 네이버 키워드 도구 API를 호출합니다. 유효한 수강생 액세스 토큰과 `ACCESS_SIGNING_KEY`가 없으면 401을 반환합니다. 수강생별 링크 발급·검증이 완성되기 전까지 이 API는 공개 조회에 사용하지 않습니다. API 키는 저장소에 넣지 않습니다.

`netlify/functions/review.mjs`는 `OPENAI_API_KEY`를 서버에서 사용하며, 같은 액세스 토큰 검증을 거친 뒤에만 소재 평가를 실행합니다. 기본 모델은 `gpt-6-luna`이며 `OPENAI_MODEL` 환경변수로 바꿀 수 있습니다.

참고한 화면: 2026-11-27 사용자 계정에 열린 네이버애즈의 파워링크 캠페인 목록, 캠페인 생성, 광고그룹 목록·생성, 키워드 등록 화면.
