# 코멘토 광고 실습실

`index.html`은 광고 관리자 형태의 교육용 화면입니다. Netlify 정적 사이트로 배포할 수 있습니다.

## 구현된 흐름

- Meta: 캠페인 → 광고 세트 → 광고. 트래픽·판매(전환) 목표, 예산, 일정, 타깃, 노출 위치, 소재, URL 및 추적 설정
- 네이버 파워링크: 캠페인 → 광고그룹 → 키워드·소재. 하루 예산, 사이트, 입찰가, 노출 매체, 키워드, 제목·설명 및 연결 URL
- 목록, 선택, 복제, 삭제, 검색, 브라우저 저장 및 교육용 성과 계산

공식 서비스 화면의 모든 기능을 재현한 것은 아닙니다. 공식 계정에 광고를 등록하거나 결제하지 않습니다. 현재 결과는 고정 CTR·CPC·전환율을 사용합니다. 실제 키워드 검색량, 소재 평가, 경매, 픽셀 이벤트는 반영되지 않습니다. 이미지 파일도 서버에 저장되지 않습니다.

## 수강생 시트 연결 계획

원본 시트 `코멘토 수강생`의 `시트1`에는 `회차`, `수강 시작`, `수강 종료`, `수강생명`, `링크`, `만료여부` 열이 있습니다. 서버 함수가 새 행마다 무작위 토큰을 생성해 `링크` 열에 기록하고, 접속 시 토큰·만료일을 검증해야 합니다. Google Sheets, AI 및 네이버 API의 자격 증명은 서버에만 보관합니다. 현재 정적 화면에는 이 연동이 아직 없습니다.
